# AWS Load Balancer Controller on Amazon EKS

This guide shows how to create the IAM role and Kubernetes
ServiceAccount used by the AWS Load Balancer Controller.

## Simple Guide

1.  Create an IAM role with **Web Identity** as the trusted entity.
2.  In the trust policy, replace `<OIDC_ID>` with your EKS cluster's
    OIDC provider ID.
3.  Attach the **Trust Policy** shown below to the IAM role.
4.  Attach the **Permission Policy** shown below to the IAM role.
5.  Name the role `AmazonEKSLoadBalancerControllerRole`.
6.  Create the Kubernetes ServiceAccount in the `kube-system` namespace
    and annotate it with the IAM role ARN.

## 1. Kubernetes ServiceAccount

This is the ServiceAccount used by the AWS Load Balancer Controller in
the `kube-system` namespace.

Before applying it, replace `<AWS_ACCOUNT_ID>` with your AWS account ID.

``` yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: aws-load-balancer-controller
  namespace: kube-system
  annotations:
    eks.amazonaws.com/role-arn: arn:aws:iam::<AWS_ACCOUNT_ID>:role/AmazonEKSLoadBalancerControllerRole
```

## 2. IAM Trust Policy

Attach this trust policy to the IAM role.

Replace: - `<AWS_ACCOUNT_ID>` with your AWS account ID. - `<OIDC_ID>`
with the OIDC provider ID of your EKS cluster.

The `sub` condition must match the ServiceAccount namespace and name:

`system:serviceaccount:kube-system:aws-load-balancer-controller`

``` json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "Federated": "arn:aws:iam::<AWS_ACCOUNT_ID>:oidc-provider/oidc.eks.us-east-1.amazonaws.com/id/<OIDC_ID>"
            },
            "Action": "sts:AssumeRoleWithWebIdentity",
            "Condition": {
                "StringEquals": {
                    "oidc.eks.us-east-1.amazonaws.com/id/<OIDC_ID>:aud": "sts.amazonaws.com",
                    "oidc.eks.us-east-1.amazonaws.com/id/<OIDC_ID>:sub": "system:serviceaccount:kube-system:aws-load-balancer-controller"
                }
            }
        }
    ]
}
```

## Important

-   The IAM role name in this guide is
    `AmazonEKSLoadBalancerControllerRole`.
-   The ServiceAccount annotation and IAM trust policy must refer to the
    same role and ServiceAccount.
-   Replace all placeholders before applying the configuration.
-   This document preserves the supplied IAM permission policy. Check it
    against the current AWS Load Balancer Controller installation
    documentation and policy version for your controller release before
    using it in production.
